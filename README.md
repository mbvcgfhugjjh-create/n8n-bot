# n8n-bot

## AI video model reference

This repository includes an upstream reference catalog of open-weight video-model families, community-labeled variants, hosted/API families, and related tools:

- [Uncensored / low-filter video model catalog](docs/UNCENSORED-MODELS.md)
- [Upstream catalog and updates](https://github.com/Anil-matcha/awesome-uncensored-ai-video-models)

**This is documentation only.** The catalog does not install an n8n node, configure a workflow, provide API credentials, or verify a model's filtering behavior. To add an operational video-generation step, choose a specific provider/API or a self-hosted inference service and configure its credentials in n8n's credential store (not in workflow exports or source control). Review the selected model's license and provider terms. Use the models lawfully and consensually; never use them to create illegal or abusive content.
